# ParkSpot v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build ParkSpot v1, an iPhone app that saves where you parked with a required photo and points you back to it, in the UI v3 look.

**Architecture:** SwiftUI with MVVM + Coordinator. The rules (geo math, what Find shows, GPS refinement) are plain value types with unit tests. Hardware services sit behind `@MainActor` protocols and arrive through `AppDependencies`; `SpotRepository` is concrete SwiftData, tested on an in-memory store. Coordinators own all navigation and presentation; views only render state and forward taps.

**Tech Stack:** Swift 6.4 (language mode 6), SwiftUI, SwiftData, CoreLocation, MapKit, AVFoundation (camera permission only), UIKit `UIImagePickerController`, Core Image, Swift Testing, XCUITest, XcodeGen. Xcode 27, iOS 27 simulator "iPhone 17".

**Spec:** `docs/superpowers/specs/2026-10-26-parkspot-design.md` (PRD v3) and `design/ParkSpot UI v3.html` (layout, colours, copy). Read both before each task.

## Global Constraints

- iOS 17.0 minimum. iPhone only, portrait only, dark only (`UIUserInterfaceStyle = Dark` plus `.preferredColorScheme(.dark)` on the root view).
- Swift language mode 6, complete concurrency checking. ViewModels, coordinators, services and `SpotRepository` are `@MainActor`; value types are `Sendable`.
- No third-party code in the app. XcodeGen is the only added build tool.
- No network use except Apple map tiles and Apple reverse geocoding. No accounts, analytics or server; photos and location never leave the phone.
- Thresholds (PRD 6b): arrow only when saved and current accuracy are both ≤ 30 m; "arrived" under 10 m; refinement ends at ≤ 20 m or 20 s after the tap; a last-known fix counts only if under 120 s old; note ≤ 140 characters; saved photo longest side ≤ 2048 px, JPEG quality 0.8.
- Distances are metric only: under 1000 m as whole metres ("84 m"), from 1000 m as km with one decimal in the user's locale ("1.2 km", Indonesian "1,2 km").
- Colours come only from `Theme` (Task 1). The accent is for actions and the active spot only.
- Type: system font (SF Pro) through text styles, so Dynamic Type works. Titles `.bold`, big numbers `.black` + `.monospacedDigit()`, pill labels uppercase with 1.6 pt tracking.
- Hit targets ≥ 44 pt. Icon-only buttons get an accessibility label from the copy.
- Text that is not copy (the "P" mark, numbers, place names) uses `Text(verbatim:)`, so Xcode doesn't extract it into the String Catalog and trip the localization test.
- All copy lives in `ParkSpot/Resources/Localizable.xcstrings` with `en` and `id` values. Keys and wording come from the `T` dictionary in `design/ParkSpot UI v3.html`, changed as in **Copy** below. Each task adds the keys its views use.
- Build and test, every task: after adding files run `xcodegen generate`, then
  `xcodebuild test -project ParkSpot.xcodeproj -scheme ParkSpot -destination 'platform=iOS Simulator,name=iPhone 17' 2>&1 | tail -25`
  It passes when the output ends with `** TEST SUCCEEDED **`. One suite: append `-only-testing:ParkSpotTests/<SuiteName>`.

## Review Focus

1. **App closed during the 20 s refinement after saving.** The spot must already be stored with the best fix so far, so persist on commit and on every improvement. Test: Task 8 `persistsEachImprovement`.
2. **Location turned off before opening Find.** Find shows photo-only with the location-off note, never stuck on "Getting your location…". Tests: Task 3 `deniedAuthorizationIsPhotoOnly`, Task 10 `deniedShowsPhotoOnly`.
3. **Double tap on "Park here".** One camera and one spot. Test: Task 9 `secondStartIsIgnoredWhileFlowRuns`.
4. **Photo file missing on disk.** Placeholder art, no crash, the row still lists. Tests: Task 5 `missingFileReturnsNil`, Task 13 `rowWithMissingPhotoStillListed`.
5. **New save or "Found it" while the previous spot is still refining.** The old refinement stops and never changes that spot again. Tests: Task 8 `newCaptureStopsOldRefinement`, `endSessionStopsRefinement`.

```swift
struct Coordinate: Equatable, Hashable, Sendable { var latitude: Double; var longitude: Double }
struct LocationFix: Equatable, Sendable { var coordinate: Coordinate; var horizontalAccuracy: Double; var timestamp: Date }
struct Heading: Equatable, Sendable { var degrees: Double }        // 0..<360, true north when available
enum Geo {
    static func distance(from: Coordinate, to: Coordinate) -> Double         // metres, haversine, R = 6_371_000
    static func bearing(from: Coordinate, to: Coordinate) -> Double          // initial bearing, 0..<360
    static func relativeAngle(bearing: Double, heading: Double) -> Double    // bearing − heading, normalised to (−180, 180]
    static func unwrap(previous: Double, target: Double) -> Double           // previous + relativeAngle(target, previous): shortest turn
}
enum DirectionPhrase: Sendable, CaseIterable { case ahead, aheadRight, right, behind, left, aheadLeft
    init(relativeAngle: Double)   // |a| ≤ 20 ahead; 20 < a ≤ 70 aheadRight; 70 < a ≤ 135 right; |a| > 135 behind; mirrored for left
    var key: String               // "dir_ahead", "dir_ahead_right", "dir_right", "dir_behind", "dir_left", "dir_ahead_left"
}
enum Formatting {
    static func distance(_ metres: Double, locale: Locale) -> String       // "84 m" / "1.2 km"
    static func roughDistance(_ metres: Double, locale: Locale) -> String  // nearest 10 m, at least 10; km rule above 1000
    static func accuracy(_ metres: Double, locale: Locale) -> String       // whole metres, "12 m"
    static func walkMinutes(_ metres: Double) -> Int                       // max(1, round(metres / 1.4 / 60))
}
```

### Task 3: Find rules

**Files:**

**Interfaces:**
- Consumes: `Coordinate`, `LocationFix`, `Heading`, `Geo` (Task 2).
- Produces:
```swift
enum LocationAuthorization: Sendable { case notDetermined, denied, authorized }
struct SavedLocation: Equatable, Sendable { var coordinate: Coordinate; var accuracy: Double }
enum FindDisplay: Equatable, Sendable {
    case precise(distance: Double, relativeAngle: Double)
    case rough(distance: Double, worstAccuracy: Double)
    case arrived
    case noHeading(distance: Double)
    case locating
    case photoOnly
    static let arrowMaxAccuracy = 30.0
    static let arrivalDistance = 10.0
    static func make(saved: SavedLocation?, current: LocationFix?, heading: Heading?, authorization: LocationAuthorization) -> FindDisplay
}
enum WalkProgress { static func value(current: Double, start: Double) -> Double }   // clamp(1 − current/start, 0…1); start ≤ 0 → 1
```
Rules, in this order:
1. No saved location → `.photoOnly`.
2. Authorization `.denied` → `.photoOnly`.
3. No current fix → `.locating`.
4. `worst = max(saved.accuracy, current.horizontalAccuracy)`. If worst > 30 → `.rough(distance, worst)`.
5. Distance < 10 → `.arrived`.
6. No heading → `.noHeading`.
7. Otherwise `.precise(distance, relativeAngle(bearing(current → saved), heading))`.
