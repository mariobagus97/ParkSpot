ParkSpot · UI design v2Gen-Z look on Apple's Human Interface Guidelines · 9 screens from PRD v2 · iPhone, iOS 17+

Idea: standard iOS everywhere, with one loud "volt" colour, big rounded type and casual copy for the personality. Volt (brand, primary actions) systemGreen (good GPS) systemOrange (weak GPS) systemRed (destructive) Type: SF Pro + SF Pro Rounded (.fontDesign(.rounded)), Dynamic Type

What changed from v1. The custom pieces are gone. Navigation, sheets, the alert, the list and the empty state are now the standard iOS ones, so the app feels native and SwiftUI builds them almost for free. The personality comes from three things only: the volt colour, SF Pro Rounded headlines, and casual copy.

HIG components used. Large titles · toolbar icon buttons (SF Symbols: clock, gearshape, map, figure.walk, location.fill) · capsule .borderedProminent buttons, 50 pt tall · sheet with grabber and medium detent · system alert with a red destructive button · inset grouped list with trailing swipe actions and a search field · ContentUnavailableView for denied access · MapKit with the standard map controls.

Colour rule. Volt marks the one main action on each screen. Status uses system colours (green good GPS, orange weak, red delete), so they mean the same thing as in every other iOS app. Light and dark mode follow the system.

Gen-Z touches. Floor numbers are tilted "stickers" so they're easy to spot at a glance. Copy is casual ("Where'd you leave it?", "Got it"), in both languages. The Park button pulses softly so it's the obvious thing to tap.

Accessibility. All targets are 44 pt or more. Text uses system text styles, so Dynamic Type works. Volt is only used as a fill behind dark text (contrast above 13:1), never as text on white. VoiceOver reads the distance as "84 meters, ahead to the right".

Sample data. Places, distances and times are examples. Grey striped boxes stand in for your photos. Icons are drawn approximations of SF Symbols; the app uses the real ones.

Navigation (MVVM + C). Park → Camera → Details sheet is the Save coordinator. Find → Map / Photo is the Find coordinator. History is its own. Views never navigate themselves.

Not designed yet. App icon, location-denied screen (same pattern as screen 9), photo viewer, Settings. They come with the build.
