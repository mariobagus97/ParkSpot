ParkSpot · UI design v19 screens from the approved PRD v2 · iPhone, iOS 17+

Idea: asphalt and line paint, like a garage floor. One bright accent, the rest stays quiet. Line yellow (accent) Asphalt Concrete Warning Type: SF Pro (system), so it follows Dynamic Type

Sample data. Place names, distances and times are examples only. Grey striped boxes stand in for the user's own photos.

One accent. Line yellow marks the actions that matter: Park here, Done, Found it, Directions. Everything else is neutral, so the yellow always means "do this".

Find decides its own layout. With good GPS (screen 4) the arrow leads. With weak GPS (screen 5) the photo and floor lead, and the arrow is gone instead of being wrong.

Navigation (MVVM + C). Park → Camera → Details is the Save coordinator. Find → Map / Photo is the Find coordinator. History is its own. The views never navigate themselves.

Accessibility. Buttons are at least 44 pt tall, text uses system styles for Dynamic Type, and the distance is read out by VoiceOver as "84 meters, ahead to the right".

Not designed yet. App icon, location-denied screen (same pattern as screen 9), and the photo viewer. They come with the build.
